<h3><a href="https://github.com/tsantos86/tskpluginmedicao">TSK TakeOff</a></h3>

<p><strong>Do desenho no AutoCAD ao mapa de medições em Excel.</strong></p>

<p>Plugin para medir alvenarias, fachadas, áreas e elementos lineares, com organização por artigo, serviço e piso.</p>

<ul>
  <li>Registo das medições no próprio DWG, com identificação visual.</li>
  <li>Deteção de vãos e confirmação dos descontos.</li>
  <li>Exportação XLSX e sincronização com Excel instalado.</li>
  <li>Testes da lógica de cálculo independentes do AutoCAD.</li>
</ul>

<p><sub>C# &nbsp;·&nbsp; .NET &nbsp;·&nbsp; AutoCAD API &nbsp;·&nbsp; ClosedXML &nbsp;·&nbsp; xUnit</sub></p>
